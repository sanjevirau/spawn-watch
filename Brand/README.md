# SpawnWatch — Brand Assets

This directory holds the SVG sources of truth for the SpawnWatch brand. The build pipeline (`Scripts/generate-icon.swift`) draws the same shapes programmatically using CoreGraphics and produces `AppIcon.icns` for the `.app` bundle, so there's no SVG → PNG conversion step in CI.

## Files

| File | Purpose | Dimensions |
|------|---------|------------|
| `AppIcon.svg` | Source design for the macOS app icon | 1024 × 1024 |
| `header.svg` | Self-contained dark hero banner used at the top of the README; works on both light and dark themes | 1200 × 320 |
| `logo-wordmark.svg` | Transparent-bg horizontal wordmark for embedding in light contexts (docs, slides, etc.) | 900 × 240 |
| `social-card.svg` | GitHub repo social preview card | 1280 × 640 |
| `hero.png` | README hero image — composited app screenshot on a brand-matched gradient with drop shadow, rounded corners, and decorative branches. Generated by `Scripts/generate-hero.swift`. | 3702 × 2090 |

## Concept

The mark is a stylized `fork()`: a single parent process on the left branches into three children on the right, each at a different opacity to suggest different lifecycle states — the brightest child is alive, the dimmer ones are exited or killed. A faint pulse ring around the focal child reinforces the "live" feel. A small green status dot adds a touch of color and signals that something is being observed in real time.

## Color palette

| Token | Hex | Usage |
|-------|-----|-------|
| `--brand-blue-primary` | `#0A84FF` | Background gradient start, primary accent |
| `--brand-blue-deep` | `#0040C9` | Background gradient end |
| `--brand-foreground` | `#FFFFFF` | Branches, dots, primary white-on-blue text |
| `--brand-status-alive` | `#34C759` | "Live" status dot |
| `--brand-text-dark` | `#0A2540` | Wordmark on light backgrounds |
| `--brand-text-secondary` | `#5E6E82` | Secondary copy on light backgrounds |
| `--brand-card-bg` | `#0A2540 → #0F1B2D` | Social card background gradient |

These match the in-app event color tokens (system blue for `exec`, system red `#FF453A` for `exit` and signal kills) so brand and product feel cohesive.

## Typography

- Headings: `-apple-system, BlinkMacSystemFont, 'SF Pro Display', system-ui, sans-serif` — weight 800, tight letter-spacing
- Body: same family, weight 400–500

When the wordmark is rendered on macOS / iOS or modern browsers, this resolves to **SF Pro Display**, matching the app's UI typography.

## Using the icon outside this build

If you need a PNG export of the icon at a custom size:

```sh
# Requires librsvg (brew install librsvg)
rsvg-convert -w 512 Brand/AppIcon.svg -o icon-512.png

# Or open the SVG in Safari, ⌘-Shift-4 to screenshot the rendered area
```

For the canonical `.icns` used by the `.app` bundle, just run:

```sh
swift Scripts/generate-icon.swift
```

That regenerates `build/Brand/AppIcon.icns` from CoreGraphics drawing code that mirrors `AppIcon.svg`.

## Regenerating the README hero image

When you retake the app screenshot, replace it and rerun:

```sh
swift Scripts/generate-hero.swift path/to/new-screenshot@2x.png
```

Output overwrites `Brand/hero.png`. The script is theme- and dimension-agnostic — it pads margins around whatever screenshot you give it.

## Don'ts

- Don't recolor the background to non-blues — the brand is anchored on system blue.
- Don't crop the squircle into a pure circle. The squircle is the macOS-native shape and reads as "macOS app" instantly.
- Don't add additional ornament inside the icon. At 16×16 (Spotlight, menu bar) every pixel matters; the mark is already at the noise floor of recognizability.
